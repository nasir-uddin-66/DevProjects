🧵 Tailor Management API

Backend Server Admin Dashboard

● Server Running

📋 API Information

Base URL: http://localhost:5000/api
Health Check: GET /api/health
Database: MongoDB (tailor)
Authentication: JWT Bearer Token

🔐 Authentication

POST /api/auth/signup
Register a new user account
POST /api/auth/login
Login and get JWT token
GET /api/auth/me
Get current authenticated user (requires auth)

👥 Users

GET /api/users
Get all users (Admin only)
GET /api/users/:id
Get user by ID
PUT /api/users/:id
Update user profile
DELETE /api/users/:id
Delete user (Admin only)

👔 Employees

GET /api/employees
Get all employees (Admin only)
GET /api/employees/:id
Get employee by ID
POST /api/employees
Create new employee (Admin only)
PUT /api/employees/:id
Update employee
DELETE /api/employees/:id
Delete employee (Admin only)

📦 Orders

GET /api/orders
Get orders (filtered by role, optional ?status=)
GET /api/orders/:id
Get order by ID
POST /api/orders
Create new order (User only)
PUT /api/orders/:id
Update order (status, assignment, etc.)
DELETE /api/orders/:id
Delete order (Admin only)

💳 Payments

POST /api/payments/stripe/create-intent
Create Stripe payment intent
POST /api/payments/stripe/confirm
Confirm Stripe payment
POST /api/payments/mobile-wallet
Process mobile wallet payment (bKash/Nagad)

📤 Upload

POST /api/upload/image
Upload image file (multipart/form-data)

📊 Dashboard

GET /api/dashboard/stats
Get dashboard statistics (role-based)
